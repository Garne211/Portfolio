🚀 Installation du Portfolio

Suivez les étapes ci-dessous pour configurer votre portfolio

1. Initialiser la base de données

Créez les tables et insérez les données par défaut dans SQLite.

Cette action créera les tables: profile, languages, projects, contents, users

2. Vérifier la structure des fichiers

Les fichiers suivants doivent être présents :

  • public/index.php - Page d'accueil
  • public/assets/js/script.js - JavaScript principal
  • public/assets/css/style.css - Styles CSS
  • api/contents.php - API traductions
  • api/languages.php - API compétences
  • api/profile.php - API profil
  • api/projects.php - API projets
  • includes/db.php - Connexion BD
  • databases/portfolio.db - Base de données SQLite

3. Configurer l'accès

Configuration recommandée :

  • Permissions des dossiers: 755
  • Permissions des fichiers: 644
  • Dossier databases/ en 775
  • Assurez-vous que PHP peut écrire dans databases/

4. Accéder aux interfaces

Une fois l'installation terminée :

  • Portfolio public: http://localhost/Portfolio/public/
  • Admin: http://localhost/Portfolio/admin/
👁️ Voir le Portfolio ⚙️ Admin Panel

5. Prochaines étapes

  • Accédez au panel admin pour configurer votre profil
  • Ajoutez vos projets dans la section Projets
  • Configurez vos compétences (langages)
  • Personnalisez les traductions (FR/EN)
  • Ajoutez les images du portfolio
  • Testez la version multilingue
